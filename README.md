### Black Hole Metric Theory & Causal Trajectory Simulations

This repository contains the numerical calculations and data visualization engines developed for the expository research paper: *"A Comparative Analysis of Classical Escape Velocities and Minkowski Metric Compression in Supermassive Horizon Geometries."* 

The codebase leverages vectorized Python routines running the native NumPy pipeline to evaluate classical Newtonian escape velocity thresholds across multiple orders of stellar magnitude (Earth, Jupiter, the Sun, and degenerate Neutron Stars). ### Key Computational Features

* **Multi-Scale Escape Vectorization:** Non-linear scaling modules that compute planetary and stellar escape thresholds.
* **Causal Cone Deformation Simulator:** A 2D spacetime grid plotting engine using Matplotlib that charts the continuous inward tilt, metric compression, and final topological inversion of localized Minkowski light cones approaching the Schwarzschild perimeter.
* **Staggered Label Optimization:** Specialized coordinate layout scripts designed to resolve visual overlaps at critical horizon limits for publication-ready figures.
